## 2024-05-19 - FeedSystem O(N log N) Sorting Optimization
**Learning:** React components dealing with large datasets and frequent renders (like `FeedSystem` updating on location change) can block the main thread if sorting and heavy calculations (like Haversine distance) are done inline during rendering. However, adding tests using Playwright requires modifying `package.json` to add the `@playwright/test` dependency. The Bolt guidelines strictly forbid modifying `package.json` without instruction.
**Action:** Always extract sorting and heavy mapping into `useMemo` hooks. Ensure to separate dependencies where possible (e.g., sorting based only on `landmarks`, mapping based on `sortedLandmarks` and `userLocation`). When verifying optimizations, strictly avoid installing new dependencies like Playwright if `package.json` cannot be modified; rely on existing static analysis like `pnpm lint` and `pnpm run build`.
