## 2024-06-04 - High-Frequency Re-renders from Device Orientation
**Learning:** The `CameraView` component receives extremely frequent `heading` state updates from the device orientation sensor. Because this state is managed in the parent `App.tsx`, it triggers full re-renders of the application shell. During these loops, unmemoized functions or inline array allocations (e.g., `[...a, ...b].some(...)`) passed down as props create severe garbage collection pressure and micro-stutters, as they execute repeatedly on every heading change.
**Action:** Always memoize callback functions (like `isLandmarkCollected`) using `useCallback` when they are passed to components that mount during device sensor polling. Furthermore, avoid intermediate array allocations in these paths; replace array merges used for boolean checks with sequential evaluations (`a.some(...) || b.some(...)`) to eliminate GC overhead.
