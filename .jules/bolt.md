## 2024-05-24 - High-Frequency Re-renders and Expensive Math in Device Orientation Loops
**Learning:** Found a major performance bottleneck where high-frequency events (`deviceorientation` updating state up to 60fps) in the parent component (`App.tsx`) cause complete re-renders of large child components (`FeedSystem`). Inside the child component, `O(N)` sorting and expensive math (Haversine formula for distance) are recalculated on every single frame because the derived arrays and callbacks passed as props weren't memoized. This blocks the main thread and causes UI lag.
**Action:** When components rely on frequent state updates (like GPS or orientation sensors), strictly memoize all derived state (`useMemo` for combined arrays and mapped results), memoize callbacks (`useCallback`), and use functional state updates (`setState(prev => ...)`) to avoid adding dependencies to callbacks. Finally, wrap pure child components in `React.memo()` to prevent cascading re-renders.
