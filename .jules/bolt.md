## 2025-02-27 - Avoid Array Merges in Hot Render Loops
**Learning:** React state updates driven by high-frequency hardware events (like `DeviceOrientationEvent` for a compass heading) cause the parent component and its children to render up to 60 times a second. If a prop function like `checkCollected` allocates an array using spread syntax (`[...a, ...b]`) and is called for multiple items during each render cycle, it generates enormous garbage collection pressure (e.g., hundreds of array allocations per second), leading to micro-stutters.
**Action:** Replace array spreads used solely for boolean aggregation with sequential evaluations (e.g., `a.some(...) || b.some(...)`) and memoize the evaluation function with `useCallback`. Use structural typing (e.g., `l: { name: string; lat: number; lng: number }`) for the explicitly typed iterator callbacks to avoid TypeScript errors without needing complex interfaces.
