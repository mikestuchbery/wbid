## 2024-05-18 - [Device Orientation High-Frequency Re-renders]
**Learning:** High-frequency events like `deviceorientation` (which fires up to 60fps) cause major main thread blocking and garbage collection thrashing if state updates trigger cascading re-renders in unmemoized child components. In React, any inline object or array creation (like `[...arr1, ...arr2]` or `.map`) in the render scope of a high-frequency component breaks referential equality, destroying the benefits of `React.memo` for all downstream consumers.
**Action:** When a component processes high-frequency events, strictly memoize all derived arrays (`useMemo`) and callbacks (`useCallback`) passed as props. Furthermore, always wrap complex functional pure child components in `React.memo()` to block these cascading re-renders from propagating down the tree. Use functional state updates to avoid adding state dependencies to `useCallback` when possible.
