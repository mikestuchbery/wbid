## 2024-05-30 - Prevent Garbage Collection Pressure in Hot Render Paths
**Learning:** `CameraView` component receives frequent device orientation updates (`heading`), causing high-frequency render loops. Passing array spreads like `[...collectedLandmarks, ...localLandmarks]` as a prop or directly evaluating it inline causes a new array to be allocated on *every single render*. This triggers significant garbage collection pressure and micro-stutters during camera interactions.
**Action:** Always memoize derived array/object props using `useMemo` when they depend on state that updates less frequently than the primary render trigger (like device orientation sensors). Replace intermediate array allocations like `[...a, ...b].some(...)` with sequential evaluations `a.some(...) || b.some(...)` to avoid GC overhead.
