## 2024-05-24 - Memoize Expensive Derived State
**Learning:** React re-evaluates variables defined directly inside the component body on every render. Inline array operations (like `[...array].sort()`) and math operations inside mapping loops (like Haversine distance calculations) recreate new arrays/values and execute O(N log N) / O(N) operations every single render cycle. If the component re-renders frequently (e.g. from location updates), this severely blocks the main thread.
**Action:** When a component derives data from props (sorting arrays, complex formatting, distances), always wrap those derivations in `useMemo` so they only recalculate when dependencies (like the array itself or user location) change. Use lookup objects (like `Record<id, string>`) to pre-calculate and access expensive loop-based derivations.
