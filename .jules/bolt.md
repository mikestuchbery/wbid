## 2025-04-07 - Avoid Array Spreads in Render Path During High-Frequency Updates
**Learning:** In `App.tsx`, the `deviceorientation` API triggers state updates up to 60 times per second (`setHeading`). Functions defined in the component scope like `isLandmarkCollected` were using array spreads (`[...collectedLandmarks, ...localLandmarks]`), causing $O(N+M)$ memory allocation and subsequent garbage collection thrashing on every single frame, leading to noticeable UI stutter during AR camera view scanning.
**Action:** When working with high-frequency sensor updates in React, wrap derived state/helper functions in `useCallback` or `useMemo`, and strictly avoid creating new arrays (via spread syntax or `.filter()/.map()`) inside these callbacks unless dependencies change. Use separate `.some()` checks or iteration loops instead of combining arrays first.
