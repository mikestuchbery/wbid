## 2025-04-25 - Prevented High-Frequency Render Allocations in App.tsx
**Learning:** `isLandmarkCollected` was recreating a combined array (`[...collectedLandmarks, ...localLandmarks]`) every time it was called. Since it's passed down as a prop to components like `CameraView` which reacts to frequent 60fps `deviceorientation` events when `isScanMode` is active, this was causing $O(N+M)$ memory allocations and contributing to garbage collection pressure and main thread stuttering. Furthermore, extracting the inline callback into a custom typed arrow function caused TypeScript type mismatch errors due to lack of inference.
**Action:** When working with high-frequency callbacks, completely eliminate array spreads. Use chained, inline `.some()` or `.every()` checks instead. Also, inline the arrow functions directly into the array methods to leverage TypeScript's automatic type inference and prevent typing issues. Always wrap the parent function in `useCallback` to preserve referential equality and reduce child re-renders.
