## 2025-03-05 - Avoid unmemoized array allocations in high-frequency render paths
**Learning:** The `CameraView` component receives frequent device orientation updates (`heading` state changes) via `App.tsx`, triggering high-frequency render loops. Using inline unmemoized arrays or object allocations—such as merging state arrays via the spread operator `[...collectedLandmarks, ...localLandmarks]` inside `App.tsx` and passing the results or deriving unmemoized callback functions like `isLandmarkCollected` from them—causes severe garbage collection pressure and micro-stutters during camera operations because a new array and function instance is created on every single frame.
**Action:** Always memoize arrays and complex derived states using `useMemo`, and wrap associated helper functions in `useCallback` when they depend on these states and are passed down to frequently re-rendering components like `CameraView`.
