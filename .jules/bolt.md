## 2024-06-15 - Array spreads in frequent render loops (CameraView heading updates) causing GC micro-stutters
**Learning:** The `CameraView` component receives highly frequent device orientation updates (e.g., `heading` state changes in `App.tsx`), which causes high-frequency render loops. Using array spread operators like `[...a, ...b].some(...)` inside these hot loops, or passing unmemoized arrays/callbacks to children, forces the JavaScript engine to constantly allocate and garbage-collect new arrays and function objects, leading to micro-stutters and dropped frames in the AR experience.
**Action:** Replace inline array spreads used for boolean checks with sequential evaluations (`a.some(...) || b.some(...)`) and strictly enforce memoization (`useMemo`, `useCallback`) for arrays and functions passed as props to prevent unnecessary re-renders and reduce GC overhead.
