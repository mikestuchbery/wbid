## 2026-04-09 - Array Spread with High-Frequency Events\n**Learning:** Recreating arrays via spread `[...arr1, ...arr2]` inside functions called on high-frequency events (like `deviceorientation` at 60fps) causes severe O(N+M) garbage collection thrashing.\n**Action:** Use independent `.some()` checks combined with short-circuit evaluation `||` to perform O(1) memory allocation during high-frequency checks.
