## 2026-04-27 - Dynamic ARIA labels for dynamic AR targeting controls\n**Learning:** In AR-heavy applications like this one where targeting logic depends on orientation sensors (deviceorientation events calculating bearings), standard `aria-label` properties on interactive controls often become inaccurate if they don't sync with the active targeting state (e.g., locking onto a nearby POI).\n**Action:** Always ensure `aria-label` properties on AR capture buttons are fully dynamic and explicitly tied to the current target state (e.g., 'Capture Castle', 'Already Discovered Castle', 'No target locked') to provide equivalent spatial context to visually impaired users who cannot rely on visual UI cues.
