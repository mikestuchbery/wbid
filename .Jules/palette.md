## 2024-05-24 - Guarding Destructive Actions for Hard-Earned Location Data
**Learning:** This location-based app involves users physically visiting locations to "collect" landmarks. Accidental deletion of these entries via a simple, un-guarded icon button in the Chronicle Feed causes irreversible loss of hard-earned real-world data, leading to severe user frustration. Additionally, key interactive elements like the search radius range slider and icon-only delete buttons lacked critical accessibility labels and keyboard focus states.
**Action:** Guard all destructive actions (like deleting a landmark entry) with a confirmation prompt (`window.confirm`) to prevent accidental data loss. Always enforce descriptive `aria-label` attributes on icon-only buttons and range sliders, and use `focus-visible` utilities (`focus-visible:ring-2 focus-visible:ring-white focus-visible:outline-none`) to ensure keyboard navigability and clear focus states across the app.
