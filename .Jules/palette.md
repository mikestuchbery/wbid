## 2025-04-21 - Added focus-visible styles to app buttons\n**Learning:** This application extensively uses custom styled buttons without standard outline/focus states, making keyboard navigation virtually impossible. We must explicitly apply `focus-visible:ring-2 focus-visible:ring-brand-accent focus-visible:outline-none` (or similar) to ensure keyboard accessibility while maintaining visual aesthetics.\n**Action:** Apply focus-visible styles whenever creating or modifying interactive elements.
