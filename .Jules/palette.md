## 2026-04-16 - Adding accessibility to Feed System Delete Buttons
**Learning:** Applying `focus-visible:ring-*` for keyboard navigators on icon-only buttons greatly enhances accessibility and visibility during tab navigation, and adding a native `window.confirm()` provides a lightweight, dependency-free safety guard against destructive UI actions.
**Action:** Use native browser prompts and focus-visible utilities for icon-only buttons universally across the project.
